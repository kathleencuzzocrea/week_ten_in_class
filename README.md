### mysql vs mysqli
mysqli is more modern, has more features, more on par with industry standard implementations of working with mysql in a php context. easy to mix them up because they have a lot of the same functions 
- 'mysqli_connect' vs 'mysql_connect'
JUST REMEMBER: we always want to be IMPROVED, mysqli is the improved version of mysql
